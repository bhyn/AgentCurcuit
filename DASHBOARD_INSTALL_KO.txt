Installation in Windows PowerShell:
1. Copy AgentCircuit_Dashboard_UI.zip into project root:
   D:\Downloads\AgentCurcuit-main\AgentCurcuit-main
2. Run:
   cd "D:\Downloads\AgentCurcuit-main\AgentCurcuit-main"
   Copy-Item .\app\control\page.tsx .\app\control\page.tsx.before-dashboard.bak
   Copy-Item .\app\control\RunAgentPanel.tsx .\app\control\RunAgentPanel.tsx.before-dashboard.bak
   Expand-Archive -Path .\AgentCircuit_Dashboard_UI.zip -DestinationPath . -Force
3. Refresh http://localhost:3000/control

Rollback:
   Copy-Item .\app\control\page.tsx.before-dashboard.bak .\app\control\page.tsx -Force
   Copy-Item .\app\control\RunAgentPanel.tsx.before-dashboard.bak .\app\control\RunAgentPanel.tsx -Force

- Server state is in memory; if enrollment resets, existing auto_enroll.py should re-register on Run.
